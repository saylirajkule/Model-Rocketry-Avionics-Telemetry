# Rocketry Avionics & Flight Systems (STES Rocketry)

## Overview
Onboard avionics firmware, sensor telemetry, and technical documentation developed as part of the **STES Rocketry Team**

## My Technical Contributions
* **Avionics & Circuit Integration:** Designed and assembled onboard electronics, custom wiring harnesses, and EMI/copper-tape shielding to ensure reliable sensor operation during high-vibration flight profiles.
* **Embedded Firmware:** Developed and tested microcontroller code for real-time telemetry, sensor data acquisition, and recovery system logic.
* **Testing & Validation:** Conducted ground-level component testing, continuity checks, and subsystem integration prior to launch operations.

## Hardware & Tools Used
* **Microcontrollers & Modules:** [ESP32 ]
* **Sensors:** [ Barometric Altimeter, Load Cells]
* **Programming & CAD:** Embedded C / C++, Autodesk Fusion 360

## Repository Contents
* `firmware/` — Flight and ground-station source code for sensor interfacing and telemetry.
* `docs/` — Complete technical project report, system architecture, and test documentation.
* `media/` — Hardware integration photos, circuit layouts, and launch documentation.
